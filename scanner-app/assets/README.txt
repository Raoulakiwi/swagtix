# SwagTix Scanner - Required Assets

Place the following assets in this folder for the SwagTix Scanner app to function properly:

- icon.png (1024x1024) - Main app icon used for app stores and device home screens
- splash.png (prefer 1242x2436 or similar) - Splash screen shown during app launch
- adaptive-icon.png (1024x1024 with background transparency) - Android adaptive icon
- favicon.png (48x48) - Icon used for web browser tabs
- beep.mp3 (short beep sound for scan success) - Audio feedback for successful scans

Note: The app will still function without these assets during development, but they are required for production builds and proper user experience. The beep.mp3 file is used for audio feedback when the "Sound" option is enabled in the app settings.
