# SwagTix Mobile App

This is the mobile app wrapper for the SwagTix Wallet, built with Capacitor to provide a native experience on iOS and Android. It wraps the web-based wallet interface, allowing it to run as a standalone mobile application.

## Prerequisites

To build and run the SwagTix mobile app, you will need:

-   **Node.js**: Version 14 or later.
-   **npm** (Node Package Manager) or **Yarn**.
-   **Git**: For cloning the repository.
-   **For Android Development**:
    -   [Android Studio](https://developer.android.com/studio)
    -   Android SDK (installed via Android Studio)
-   **For iOS Development (macOS only)**:
    -   [Xcode](https://developer.apple.com/xcode/)
    -   [CocoaPods](https://cocoapods.org/) (installed via `sudo gem install cocoapods`)

## Building the App

The mobile app build process involves first building the core SwagTix Wallet (the web interface) and then integrating it into the Capacitor wrapper.

### 1. Build the SwagTix Wallet (Web Interface)

Navigate to the `wallet` directory and build the production version of the web interface. This will generate the static web assets that the mobile app will wrap.

```bash
# Navigate to the main project root
cd ~/swagtix

# Go into the wallet directory
cd wallet

# Install wallet dependencies (if not already done)
yarn install # or npm install

# Build the production version of the wallet
# This creates the 'dist' folder with the web assets
yarn build:pro # or npm run build:pro
```

### 2. Build the Mobile App Wrapper

Now, navigate to the `mobile-app` directory and run the custom build script. This script will copy the built wallet assets into the mobile app's `www` directory and prepare the native projects.

```bash
# Navigate to the mobile-app directory
cd ~/swagtix/mobile-app

# Install mobile app dependencies (if not already done)
npm install

# Run the custom build script
# This script copies the wallet build into 'www' and runs 'npx cap copy'
npm run build
```

### 3. Open Native Projects

After the `npm run build` command completes, you can open the native projects in their respective IDEs:

**For Android:**

```bash
npm run build:android
# This will open Android Studio with your project
```

**For iOS (macOS only):**

```bash
npm run build:ios
# This will open Xcode with your project
```

From Android Studio or Xcode, you can then build, run, and debug the app on emulators or physical devices.

## Project Structure

-   `capacitor.config.json`: Capacitor configuration file.
-   `www/`: This directory will contain the web assets of the SwagTix Wallet after `npm run build` is executed.
-   `android/`: The native Android project generated by Capacitor.
-   `ios/`: The native iOS project generated by Capacitor.
-   `build.js`: A custom Node.js script that automates copying the built wallet assets into the `www` directory and running Capacitor commands.

## Customizing the Mobile App

-   **App Icon & Splash Screen**: These can be customized within the native Android Studio and Xcode projects. Capacitor also provides tools to generate these from a single source image (`npx cap resources`).
-   **App Name & ID**: Modify `appName` and `appId` in `capacitor.config.json`.
-   **Wallet URL**: In `capacitor.config.json`, the `server.url` is currently set to `http://localhost:3000`. **For production deployments, you MUST change this to the public URL of your SwagTix Admin Interface backend.**
-   **Native Plugins**: You can add custom native functionality (e.g., advanced QR scanning, biometric authentication) by creating Capacitor plugins. A placeholder `qr-scanner` plugin is included in `native-plugins/`.

## Important Notes

-   **Security**: Ensure your backend server (hosting the wallet and contract management APIs) is securely deployed and accessible via HTTPS in a production environment.
-   **Wallet URL**: The `server.url` in `capacitor.config.json` is crucial. For development, `localhost` works. For production, it must point to your live backend API URL.
-   **Cordova.js**: The `index.html` includes `cordova.js`. This is a shim provided by Capacitor for compatibility with some plugins and is automatically handled by Capacitor. You do not need to install Cordova separately.
-   **Back Button (Android)**: Basic back button handling is included in `www/index.html` to navigate within the web view or prompt to exit the app.
